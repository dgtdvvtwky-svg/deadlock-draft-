# Deadlock Драфт

Сайт для драфтов в Deadlock: баны и пики по очереди, таймер хода, лобби с составами 6 на 6.

- **Вход через Steam** (официальный Steam OpenID) или гостем под ником: сайт открыт всем.
- **Комнаты по ссылке** `/r/КОД`. Все видят ходы мгновенно, очередь и таймер проверяет сервер.
- **Статистика игроков** из открытого Deadlock API (на нём же построен StatLocker): ранг, игры и процент побед на каждом герое, ссылка на профиль StatLocker.
- **Лобби после драфта**: игроки занимают своих героев кнопкой «Это я», хост вставляет код приватного лобби из игры, состав копируется в Discord. Создать лобби внутри самой игры сайт не может: у Deadlock нет для этого открытого API.
- Без зависимостей: нужен только Node.js 18 или новее, `npm install` не требуется.

## Запуск на своём компьютере

```bash
node server.js
```

Откройте http://localhost:3000. Вход через Steam работает и на localhost.

## Публикация в интернет (бесплатно, Render)

1. Загрузите эту папку в репозиторий на GitHub.
2. На https://render.com: **New → Blueprint**, выберите репозиторий (Render прочитает `render.yaml`). Или **New → Web Service**, Runtime: Node, Start Command: `node server.js`.
3. В **Environment** укажите `BASE_URL` = адрес, который выдал Render, например `https://deadlock-draft.onrender.com` (без слэша в конце). `SESSION_SECRET` Blueprint создаст сам; для Web Service впишите любую длинную случайную строку.
4. Откройте адрес: сайт работает, вход через Steam тоже.

Учтите: бесплатный сервер Render засыпает после 15 минут без посетителей (первое открытие потом занимает около минуты), а комнаты хранятся в файле и сбрасываются при перезапуске. Для постоянной работы подойдёт платный тариф или свой VPS.

## Свой сервер (VPS)

```bash
docker build -t deadlock-draft .
docker run -d -p 3000:3000 -v $PWD/data:/app/data \
  -e BASE_URL=https://draft.example.com -e SESSION_SECRET=длинная-строка deadlock-draft
```

Перед ним поставьте HTTPS-прокси (Caddy или nginx). Для nginx отключите буферизацию у `/api/rooms/` (`proxy_buffering off;`): обновления комнат идут потоком.

## Настройки (переменные окружения)

| Переменная | Нужна? | Что делает |
|---|---|---|
| `BASE_URL` | да, в интернете | Адрес сайта для возврата из Steam |
| `SESSION_SECRET` | желательно | Подпись входа; без неё создаётся `data/.secret` |
| `STEAM_API_KEY` | нет | Ник и аватар из Steam сразу после входа (иначе берутся из Deadlock API) |
| `DEADLOCK_API_KEY` | нет | Ключ Deadlock API при большой нагрузке |
| `STATLOCKER_PROFILE_URL` | нет | Шаблон ссылки на профиль, `{id}` заменяется на account id |
| `PORT`, `DATA_DIR` | нет | Порт и папка для данных |

## Как устроено

- `server.js`: HTTP-сервер, Steam OpenID, сессии в подписанной cookie, комнаты, поток обновлений (SSE), прокси к Deadlock API с кешем.
- `public/`: интерфейс (`index.html`, `app.js`, `style.css`).
- Список героев встроен (44 на ноябрь 2026) и при запуске обновляется из Deadlock API, вместе с портретами. Новые герои появятся сами в группе «Новые».
- Хост может отменить ход, бросить монетку, удалить комнату и создать реванш. Если место капитана пустое, за команду ходит хост.
